# 普通话朗读稿

每句只读一遍，语速自然，句与句之间稍作停顿。读错了也请继续，不要重读。

*草稿由非母语者编写，请母语者先校对再录音。标注拼音只为说明声调对比。*

## 声调对比句

这些句子里有只靠声调区分的词，用来检查识别和合成是否保留了意义。

26. 妈妈骑马，马慢，妈妈骂马。（mā, mǎ, mà）
27. 我想买一个，不是卖一个。（mǎi / mài）
28. 他们在睡觉，不是在吃水饺。（shuìjiào / shuǐjiǎo）
29. 是四，不是十；是十四，不是四十。（sì / shí）
30. 我要问他，不是吻他。（wèn / wěn）
31. 眼睛不舒服，不是眼镜坏了。（yǎnjing / yǎnjìng）
32. 这是汤，不是糖。（tāng / táng）

## 自由发言话题

请像和同事聊天一样，说大约四分钟。选两到三个：

- 下个月的安排，尽量带上真实的日期和人名。
- 最近改变了看法的一件事，以及原因。
- 一个带数字的计划：预算、旅行或日程。
- 一次因误会引起的问题，以及怎么解决的。
